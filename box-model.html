CSS Box Model Teaching Examples

1. The Four Parts of Every Box

Every HTML element has four parts:

Margin
Border
Padding
Content
  • Content: The actual text or image (teal area)
  • Padding: Space between content and border
  • Border: The red outline around the element
  • Margin: Space outside the border, separating from other elements

2. How Each Part Affects Size

Notice how adding padding, border, and margin makes boxes take up more space:

100x100
No extras
100x100
+ Padding
100x100
+ Border
100x100
+ Margin
100x100
+ All

All boxes have width: 100px and height: 100px, but they take up different amounts of space!

3. Box-sizing Property

This property changes how width and height are calculated:

content-box (default)

Width = content only
Total width = 200 + 40 + 20 = 260px

border-box

Width = content + padding + border
Total width = 200px exactly

/* content-box (default) */ .content-box { width: 200px; padding: 20px; /* adds to width */ border: 10px; /* adds to width */ box-sizing: content-box; } /* border-box */ .border-box { width: 200px; /* total width stays 200px */ padding: 20px; /* included in width */ border: 10px; /* included in width */ box-sizing: border-box; }

4. Simple Exercise

Try to predict: What's the total width of this element?

.mystery-box { width: 150px; padding: 25px; border: 5px solid red; margin: 10px; box-sizing: content-box; }

Answer: 150 + 50 (padding) + 10 (border) = 210px total width
Note: Margin doesn't affect the element's width, just the space around it.
